NetRexx - a human oriented languge for the JVM

NetRexx is a human oriented language designed by M.F.Cowlishaw, who has been also the original Author of 'classic Rexx', quite well known and used since decades in the IBM World. NetRexx is a blend of the best principles of Java and Rexx, and may be used as an Interpreter and/or Compiler using existing Java Classes and Methods in a natural and more readable Code, thus shortening programming time a lot.

About the Speaker: Thomas Schneider has been working in the IT-Business since 1966, using various
languages such as Algol, RPG, PL/I, Basic, Fortran 77, C, Rexx, Cobol, and GEISCO's Tabol and DMS.

When appointed as Project manager for the Year 2000 and EURO Transition
phase at Donauland, an Austrian daughter of Bertelsmann, Germany, he detected
NetRexx, and has been fascinated by the ease of learning and it's power.

Using NetRexx, he did develop for instance DB-123, a generalized Database Migration
Software (see www.db-123.com (http://www.db-123.com/)), as well as Rexx2Nrx, the classic Rexx to NetRexx Converter.

PerfCake: Get the performance results NOW!

In the presentation we will introduce you to a modern performance testing tool PerfCake. We will guide you through a typical process of developing a performance test for a REST and an A-MQ service. We will show you how to speed up the testing by smart PerfCake features. This is a key technology differentiator to other testing frameworks. In the end we will see chart outputs and the results stored in a repository where they can be accessed at anytime. The repository data can further provide reports for business executives.

About the Speakers: Martin Večeřa - Experienced team leader of several Quality Assurance teams for various JBoss Middleware products from both technical and people manager point of view. An autocratic manager of the best performance testing tool PerfCake.
Pavel Macík - Pavel is a senior QA engineer working in Red Hat as a part of the JBoss QE team with the main focus on performance for over 5 years. He is also one of the core developers of the PerfCake performance testing framework.
