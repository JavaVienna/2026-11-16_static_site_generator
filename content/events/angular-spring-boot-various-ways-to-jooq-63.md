**Angular ♥ Spring Boot**
\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-
Angular und Spring Boot arbeiten sehr gut miteinander zusammen. Aber warum soll das Deployment dann getrennt voneinander stattfinden? In diesem Talk erklärt Erich Stadler, warum ein gekoppeltes Deployment Sinn macht und wie hiermit noch weitere Vorteile "herausgekitzelt" werden können. Gemeinsam sehen wir uns an, was WebJars sind, wie man mit Thymeleaf arbeitet, Angular in den Maven Prozess einbindet, das Ganze in Spring Boot einbindet und schlussendlich den Reverse Proxy richtig konfiguriert.

**Various ways to jOOQ**
\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-
JOOQ behauptet von sich "the best way to write SQL in Java" zu sein. Das Schweizer Taschenmesser der Datenbankzugriffstechnologien bietet allerdings noch viel mehr! Wir wollen in unserem Talk auf die einzelnen Einsatzmöglichkeiten von jOOQ eingehen: - Einsatz in green-field Projekten - Als Alternative zu JPA - Als Erweiterung zum Einsatz von JPA / Spring Data JPA Persistence Implementierungen - Für die Analyse und Anbindung von Legacy Systemen Unser Motto lautet ... the right tool for the right job. Wir wollen euch zeigen wie und wann jOOQ das richtige Werkzeug sein kann!
