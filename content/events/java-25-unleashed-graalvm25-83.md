**Java 25 Unleashed: New Features, AOT Compilation, and Project Leyden**
Java 25 is here! 🚀 In this talk, we’ll walk through the most exciting new features, with a spotlight on Ahead-of-Time (AOT) compilation and Project Leyden—technologies that promise faster startup, smaller footprint, and a new era for Java in cloud and serverless environments.

**About the Speaker**
[Mohsen Ahmadian](https://www.linkedin.com/in/mohsenahmadian) is a Staff Engineer at Sportradar, building large-scale, high-performance sports-betting platforms in Vienna. With extensive experience in Java, Spring Boot, and AWS serverless systems, he focuses on modernization projects that bring cutting-edge Java features into production. Mohsen has also taught programming at university and is passionate about sharing knowledge on the evolution of the Java platform, clean code practices, and performance-driven architecture.

**What's new in GraalVM 25**
GraalVM is a family of technologies for polyglot programming: efficient execution of programs written in various programming languages, including integration between languages. This talk will recall some of the GraalVM features everybody loves, then it will present and demo some new developments that arrived with the recent release of GraalVM 25.
