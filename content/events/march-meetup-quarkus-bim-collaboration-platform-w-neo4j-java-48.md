Project Quarkus: Kubernetes Native Java stack tailored for GraalVM
-----
Project Quarkus promisses a JavaEE Microprofile Stack compiled down to native bytecode using GraalVM. This promises startup times of <10ms. We'll take a look at the promises made and see if they hold up. Maybe we'll even see if its possible to run them on AWS Lambda.. lets see!

About the Speaker: Dominik Dorn is a Freelance Software Engineer from Vienna. Since 2010 he leads the association Java Student User Group which is known for the "Java Vienna Meetup" and as a Co-Organizer of the "DevFest Vienna". He's been speaking on conferences like JavaOne San Francisco, ConFess, JDD Krakow and Voxxed Days. His special interests are on high-concurrency, high-throughput and event-driven distributed systems based on Java and Scala. You can follow him on twitter: @domdorn

Second talk: A BIM collaboration platform using Neo4j and JAVA microservices

BIM is revolutionising the way buildings are planned, built and operated. Collaboration on 3D building models, however, pose great technical challenges both in software and in infrastructure. We will see how different architectural patterns and choosing the right technologies help us build a system of such complexity.

About the speaker: Adam Eri is a software architect specialised in cloud based micro-service solutions, continuous delivery of mobile apps, code quality, high availability. Besides these, he is building apps and games for all Apple platforms. He designed and built state-of-the-art online gaming solutions, e-commerce systems, a popular fitness application; using various technologies like JavaScript, node.js, Swift and Java.
