**Reasonable Cloud Practices with Java on AWS**
How to start a cloud project? How to find a reasonable AWS cloud service to run your Java application? How to structure and architect a Java application? How to debug and test a cloud application? ...and what is actually "Cloud Native"? After answering such questions, I plan to spend as much time in live coding and deployments as possible. In this JUG session, I will create a "boring" MicroProfile application locally, debug it, then deploy it as serverless AWS Lambda, and discuss the architectural and economic choices on the go. Your questions always have the highest priority and will be immediately answered.

About the speaker:
**Adam Bien** ist Entwickler, Consultant, manchmal Konferenzsprecher, Autor und Java / Jakarta (SE/EE) / MicroProfile Enthusiast Adam Bien (adambien.blog) arbeitet mit Java seit JDK 1.0, JavaScript seit LiveScript und hat immer noch sehr viel Spass am Programmieren. Adam veranstaltet regelmässig Java EE / WebStandards / JavaScript Workshops am Flughafen München (http://airhacks.com).
