**Event-Driven Workflow Orchestration with Kestra for the Streaming Stack: Kafka, Flink, Fluss, and Beyond**
Data streaming moves events in real time, but streaming alone does not run the business. Flink jobs need deployment and monitoring, lakehouse tables need maintenance, and events need to trigger processes with retries, human approval and an audit trail. AI agents act on events autonomously and need the same governance.

This talk shows how event-driven workflow orchestration complements the streaming stack and goes beyond it, because not everything is a stream. Kestra is an open source platform built in Java under Apache 2.0. It provides unified orchestration of real-time and batch workloads across data, AI, infrastructure and business processes. A practical walkthrough connects Apache Kafka, Apache Flink and Apache Fluss with APIs, databases and the lakehouse, all the way to trusted agentic AI.

**About the Speaker**
Kai Waehner is Global Field CTO at Kestra, the open source platform for unified orchestration across data, AI, infrastructure and business processes. In parallel, he advises enterprises, software vendors and investors as an independent consultant. Previously, he spent over nine years as Global Field CTO at Confluent, helping to build the Apache Kafka and Flink ecosystem. He writes about data streaming and workflow orchestration at [www.kai-waehner.de](https://www.kai-waehner.de).

**Functional Java or "living without nulls"**
With the recent additions (some still in preview), Java gets *quite close* to a real functional programming language. In this talk, we'll take a look at where things are, as well as a new Java Library that aims to bridge some of the last remaining gaps.
