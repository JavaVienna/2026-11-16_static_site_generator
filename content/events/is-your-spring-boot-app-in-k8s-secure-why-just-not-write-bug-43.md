**Is your spring boot application in Kubernetes secure?**
Modern platforms make it increasingly easy for developers to deploy their applications to Kubernetes. Very often, security is on the losing side of this trade-off, with many default settings prioritizing velocity and deployment speed. In this talk we will look at the pitfalls and real-life security misconfigurations when deploying a spring boot application on Kubernetes.

**About the Speaker**
[Damjan Gjurovski](https://www.linkedin.com/in/damjan-gjurovski-362b3a206/) is the CEO/CTO of Posedio and has worked with some of the biggest Austrian companies and service providers in the retail, education, and finance sector. He enjoys working with new, open- source cloud technologies with focus on security and scalability.

**Have you ever considered just not writing bugs? (EN)**
In this talk, we will consider several snippets of Java code that contain mistakes and try to summarize which tools and approaches we can use nowadays to avoid similar bugs in your code. Java programmers with any background and experience are welcome, only basic Java knowledge is necessary.

**About the Speaker**
Tagir Valeev works as a technical lead at JetBrains. He participates much in improving Java static analysis in IntelliJ IDEA that helps you to detect bugs. He is an OpenJDK committer and Java Champion. Also, he is the author of the recently published book "[100 Java Mistakes and How to Avoid Them](https://www.manning.com/books/100-java-mistakes-and-how-to-avoid-them)".
