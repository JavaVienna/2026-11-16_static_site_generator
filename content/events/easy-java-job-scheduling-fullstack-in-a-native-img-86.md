**JobRunR - Easy Java Job Scheduling**
We will take a look at JobRunR, a library for (distributed) Java Job-Scheduling. Too much work for your main app? Just attach a few RaspberryPis to help you out.
\- What is JobRunR
\- How can Jobs be scheduled
\- The Management Dashboard
\- Storage Engines
\- Samples with Spring\, Quarkus\, Micronaut

**Fullstack in a native.img**
We're are going to explore how to make native images using GraalVM with Spring Boot 4. We'll explore different ways on how you can create your UIs (Vaadin 25, REST API + HTMX) as well as how to integrate Database Access and JobRunR Jobs into the native image.
